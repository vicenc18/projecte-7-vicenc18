# Presència Digital per a FoodLogístic S.A.

## Necessitat Detectada

Una de les primeres inquietuds que FoodLogístic S.A. ens ha traslladat és la necessitat urgent de **millorar la seva presència a Internet**.

La seva pàgina web actual presenta diverses mancances:

- Disseny **estèticament desactualitzat**
- Infraestructura **tècnicament obsoleta**
- **Incompliment** de la normativa vigent:
  - LOPDGDD (Protecció de dades)
  - LSSI-CE (Serveis de la societat de la informació i comerç electrònic)

Aquesta situació afecta directament la imatge corporativa, la confiança dels clients i pot suposar riscos legals.

##  Objectiu de l’Activitat

FoodLogístic no només vol una proposta teòrica. Vol veure una **prova funcional real** de com serà la seva nova identitat digital.

Per aquest motiu, el projecte inclou la **publicació real** del lloc web en un servidor públic, demostrant la nostra capacitat tècnica i professional.

##  Objectius Clau del Desplegament

###  Publicació Professional amb GitHub Pages

Utilitzarem GitHub Pages per:

- Publicar el lloc web sota una **URL pública**
- Convertir el codi font en una web plenament operativa
- Mostrar al client un entorn real i funcional

###  Documentació del Projecte (README.md)

Caldrà crear un fitxer `README.md` professional que actuï com:

- Carta de presentació de la nostra empresa
- Presentació de l’autor del projecte
- Documentació tècnica i estructural del treball realitzat

Aquest document serà visible públicament al repositori i reforçarà la nostra imatge professional.

### Control i Analítica amb StatCounter

> *No es pot millorar el que no es mesura.*

Integrarem una eina d’analítica web com **StatCounter** per:

- Monitoritzar les visites a la web
- Conèixer el comportament dels usuaris
- Disposar de dades reals per a futures millores

## Resultat Esperat

Al final de l’activitat disposarem de:

- Una web moderna, funcional i pública
- Compliment de la normativa legal vigent
- Documentació professional del projecte
- Sistema d’analítica integrat
- Una demostració real i convincent per a FoodLogístic S.A.

Aquesta prova funcional serà clau per guanyar la confiança del client i assegurar un projecte a llarg termini.
